# decruptor.github.io

Public site of Decruptor — independent research on the computational side of
lost cryptographic keys.

- `src/` — Vite + React source, built from the Decruptor design-system kit
  (components and pages are the kit's files, wired for production).
- `dist/` — production build, deployed to the `gh-pages` branch (GitHub Pages
  serves that branch at https://decruptor.github.io).

Build: `npm install && npm run build`. Content sources live in
`puzzle-hq/website/content/` (design kit `uploads/` are identical copies).

Corrections: open an issue on this repo or any `decruptor/*` repo.
